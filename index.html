The Last Light

A seated hands-first storytelling diorama built with Meta Immersive Web SDK (IWSDK). Restore the storm-battered lighthouse island by returning three lost memory fragments to their shrines.

How to Interact
Mouse Click Click fragment or HUD button
1 2 3 Place Warmth, Life, Hope
R Restart experience
VR Hand Pinch Pinch & carry in WebXR

Testing Note: This experience was engineered and tested with desktop WebXR emulation (Meta Quest 3 profile) and standard desktop mouse/keyboard input. Immersion features require a WebXR-compatible browser or headset.
