### 2. Video Description

```text
"Build a Memory. Step Inside Its Story."

ECHOCRAFT VR: The Last Light is an atmospheric, seated hands-first WebXR diorama experience created for the Meta VR Start Developer Competition 2026 (Entertainment Track).

In a world where the guiding beacon is fading, players sit before a miniature, storm-battered coastal diorama. By reaching out with their hands to place three lost memory fragments—Warmth, Life, and Hope—into ancient stone shrines, players trigger real-time transformations that calm the raging tempest, bloom coastal flora, and unlock a radiant golden sunrise that expands to surround the viewer.

Built with Meta's official Immersive Web SDK (IWSDK v1.1.0) and Three.js, ECHOCRAFT VR features:
✨ Seated hands-first WebXR ergonomics (no roomscale walking required)
✨ Custom stylized 3D low-poly art authored via Blender MCP integration
✨ Zero-dependency procedural Web Audio API spatial sound engine
✨ Comfort-first room-scale diorama expansion with zero forced camera movement
✨ 100% accessible via Meta Quest Browser or desktop WebXR emulation
```
